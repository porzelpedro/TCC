# Sistema de Orientação para Descarte de Resíduos Utilizando Inteligência Artificial

Aplicação web desenvolvida para auxiliar a população na identificação correta de resíduos sólidos, fornecendo orientações de descarte baseadas em Inteligência Artificial, além de mapear pontos de coleta e ecopontos próximos.

## 🔗 Links de Acesso
* **Aplicação rodando na web:** https://porzelpedro.github.io/TCC/ 
* **Repositório no GitHub:** https://github.com/porzelpedro/TCC.git

## ✅ Checklist de Critérios do Projeto

A tabela abaixo demonstra como a aplicação atende aos critérios exigidos para a entrega do projeto frontend:

| Critério | Status / Atendimento | Justificativa / Como foi implementado |
| :--- | :--- | :--- |
| **1. Deploy e Funcionamento** | Atendido | O projeto está publicado e funcional na web, abrindo corretamente no navegador sem erros de carregamento de arquivos (`CSS`/`JS`) ou telas em branco. |
| **2. Interatividade sem Recarregamento** | Atendido | Os formulários e botões utilizam eventos em JavaScript com `preventDefault()`, permitindo cadastrar, editar e interagir com os dados de forma dinâmica, sem recarregar a página. |
| **3. Persistência de Dados** | Atendido | Os dados inseridos ou alterados pelo usuário são salvos utilizando o `localStorage`, garantindo que continuem visíveis na tela mesmo após atualizar a página (pressionar F5). |
| **4. Estabilidade do Console** | Atendido | O sistema foi testado exaustivamente através do DevTools (F12 > Console) e todas as interações ocorrem sem a exibição de erros ou alertas em vermelho. |
| **5. Adaptabilidade e Responsividade** | Atendido | O layout foi construído com design responsivo, adaptando-se perfeitamente a telas de celulares e desktops sem quebras ou barras de rolagem horizontal indevidas. Conta também com descrições em imagens para acessibilidade. |
